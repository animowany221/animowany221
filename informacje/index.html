skąd wziąć domenę?

ta strona została stworzona przy pomocy github pages dobrym roziwązaniem jest też duck dns i tailscale oczywiście jeżeli chce się mieć profesjonalną domenę, można zapłacić za domenę .pl, .com albo inne.

jak stworzyć stronę internetową?

można użyć edytorów tekstu jak notepad++ lub visual studio code, są także narzędzia graficzne (patrz Google Sites).

jak wyświetlić stronę w Google?

należy dodać stronę do Google Search Console, później wpisać adres naszej strony i kliknąć request indexing. jeżeli mamy jakieś podstrony, dobrą praktyką jest także utworzenie mapy strony.
